# Dan Ichimescu

**Graphic designer who automates production work with code.**
Bucharest, Romania · [LinkedIn](https://www.linkedin.com/in/dan-ichimescu-4257098/) · [Batch-resize case study](https://resize.magic.re/) · [Behance](https://www.behance.net/constantindan) · constantindan@gmail.com

I have worked in advertising and print production since 2016 (Hogarth Worldwide, INDG, Saatchi & Saatchi).
Every piece of code in these repositories exists for the same reason: a repetitive task was eating
hours of the day, so I wrote a tool to do it.

**Two of these tools became the way my whole team worked.** Nobody asked for them: I saw the same
manual steps repeated all day, automated them on my own initiative, and my colleagues adopted the result.

- At **Hogarth**, the [InDesign batch-resize script](https://github.com/kowalschi/indesign-batch-resize)
  (2020) — the team used it in production for over four years. [Case study →](https://resize.magic.re/)
- At **INDG**, the [Board for Batch Command](https://github.com/kowalschi/Board-for-batch-command)
  desktop app (C#, 2021–2022) — used daily by the whole artwork team for years.

I started scripting in **2019–2020, before AI coding assistants existed**, learning from the Adobe
scripting reference, forums and Stack Overflow. Since 2024 I also work with AI tools (Claude, ChatGPT)
as a pair programmer: I define the problem, design the workflow, test on real production files and
keep the result maintainable.

## Timeline

- **2019–2020** — first InDesign scripts (page geometry, bleed, health-warning bands), then the first
  version of the batch-resize script at Hogarth. Hand-written, no AI. My own initiative; the team
  adopted it and kept using it for over four years.
- **2020–2022** — e-book production pipeline for publishers: metadata and ISBN from Excel, styles,
  hyperlinks, footnotes, batch export. Hand-written, no AI.
- **2021–2022** — C# desktop app for the 3D product-visualisation pipeline at INDG. Written on my own
  initiative with what I knew from JavaScript plus the .NET docs and Stack Overflow; it became the
  whole artwork team's daily tool.
- **2023–2025** — batch resize grows to multi-master, Excel-driven, Windows + macOS.
- **2025–2026** — web development course (HTML, CSS, JavaScript, React, Node.js) at Scoala Informala de IT.
- **2026** — AI-assisted projects: a book proofreading pipeline (Python + InDesign) and a full-stack job tracker.
